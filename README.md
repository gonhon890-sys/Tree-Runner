# Tree Runner

Tree Runner is a RuneLite plugin designed to help plan and track tree farming runs in Old School RuneScape.

## Features

- Customisable tree farming routes
- Automatic detection of successful sapling planting
- Tree growth timers for individual patches
- Patch highlighting during farming runs
- Normal tree patches
- Fruit tree patches
- Hardwood tree patches
- Calquat patches
- Celastrus
- Redwood
- Crystal trees
- Fossil Island hardwood tracking
- Sapling requirement tracking
- Travel method recommendations
- Inventory-aware travel options
- Persistent patch timers
- Tree species icons in Patch Times

## How it works

Choose the patches you want to include in your farming run and Tree Runner creates a route through the selected locations.

When a sapling is successfully planted, Tree Runner automatically records the patch and advances the route.

The Patch Times tab displays your planted trees and their estimated remaining growth times.

## Installation

Tree Runner is intended for distribution through the RuneLite Plugin Hub.
